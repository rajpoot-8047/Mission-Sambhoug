# Error Fixer Guard

## Diagnostics & Lint Enforcement
1. **Const Optimization:**
   - Enforce `const` on all immutable widget constructors and collections.
2. **Null Safety:**
   - Explicit null handling (`?`, `??`, `!`).
   - Guard callbacks and map lookups.
3. **Type Safety:**
   - No implicit `dynamic`. Annotate all function signatures and parameters.
4. **Style Consistency:**
   - Maximum line length <= 100 characters.
   - Clean trailing commas for multi-line argument lists.
